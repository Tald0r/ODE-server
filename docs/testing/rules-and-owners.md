# Rules and the tests that own them

Every architectural rule below is owned by something that fails, never by a memory. The full
ratchet table (R1-R18), with the command that measures each number and the reason it exists, is
in [the restructuring plan](../reviews/RESTRUCTURING.md); `tests/ratchet/ratchets.sh` is the
enforcing copy, run by ctest as `ratchets` ([ratchets](ratchets.md)).

This is the whole table in one place, as `CLAUDE.md` carried it until it became an index. Each
area concept repeats its own rows beside the reasons for them (linked in the last column); a
change to a rule, its owner or its failure updates the row here and in that concept in the same
commit. Where an area concept names a fixture without its target, the target is its folder's
runtime test binary.
